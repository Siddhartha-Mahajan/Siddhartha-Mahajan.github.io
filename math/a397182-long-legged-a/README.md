# A397182 exact-formula web page

Static publication page for:

**Siddhartha Mahajan and Paras Chopra, _The Exact Region Formula for Arrangements of Constrained Long-Legged A's_.**

Open `index.html` directly or serve this directory with any static server.

## Structure

- `index.html` — complete web proof, figures, certificate ledger, provenance, and downloads.
- `assets/css/styles.css` — page styles; the page background is pure white.
- `assets/js/main.js` — reading progress, active navigation, formula copy action, and certificate filters.
- `assets/figures/` — all-n blow-up schematic, the primary complicated-coordinate `n=4` witness, and the low-height alternate witness.
- `assets/downloads/certificates/` — exact rational certificates `n04.json` through `n16.json`, plus the alternate low-height `n=4` certificate.
- `assets/downloads/scripts/` — exact standard-library Python verifiers.
- `assets/downloads/manuscript/` — PDF, LaTeX, and bibliography files.
- `assets/downloads/verification/` — archived exact verifier outputs.

All download links are relative, so the page works on GitHub Pages without a build step.
