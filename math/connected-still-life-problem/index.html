Connected Still Life

Siddhartha Mahajan

Problem statement, CAISc 2026 Verifiable Problems Track, April 15, 2026. Reviewed by Dr. Ankan Pal (BITS Pilani).

PDF Original problem page Paper with the exact values

Abstract

A still life of Conway's Game of Life is a pattern that does not change: every live cell has two or three live neighbours and no dead cell has exactly three. The maximum density of an unconstrained still life approaches 1/2 asymptotically, and the unconstrained finite-box optimum is known exactly. Requiring the live cells to form a single connected group, under horizontal, vertical, and diagonal adjacency, changes the finite-box optimization problem, because isolated stable pieces can no longer be tiled freely. This problem asks for connected still lifes in an n × n box with as many live cells as possible, for the box sizes n = 8, 9, 10, 11, 13, 15, 16, 17, 19, 20, 21, 31, 32. For small n good solutions are known; for n ≥ 16 the best-known connected patterns came from ad hoc searches and could be suboptimal. The connected optimum can be close to the unconstrained finite-box optimum for some sizes, so the gap is instance-dependent. Every submission is checked automatically.

Verification

A submission gives n, the claimed number of live cells, and the n × n binary grid. It is accepted when the grid has the right shape, every live cell has exactly 2 or 3 live neighbours, no dead cell in the box or its one-cell exterior ring has exactly 3 live neighbours, all live cells are 8-connected, and the live-cell count matches the claim.
