# A003829 visualisation bundle

This is a static, publishable mathematical-blog bundle for the manuscript visualisation.

Entry point: `index.html`.

Contents:

- `index.html` — the article page.
- `assets/css/styles.css` — all styling.
- `assets/js/main.js` — the small circle-selector interaction.
- `assets/figures/*.svg` — local SVG visualisations for n=3 through n=9.
- `assets/images/m20_construction_annotated.png` — manuscript construction image retained for reference if needed by future edits.

No generated scripts, certificates, raw research data, or bounds plot is included in this publishable bundle.

The page is self-contained for static hosting: it uses local CSS/JS/SVG assets and no external fonts or JavaScript libraries.
