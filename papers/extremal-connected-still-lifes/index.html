Extremal Connected Still Lifes in Square Boards

Siddhartha Mahajan

Lossfunk Research Laboratory, October 2026.

PDF Data and verifiers OEIS A398723 The problem

Abstract

Let C(n) denote the largest population of a stable Conway Life pattern in an n × n square whose live cells form one component under Moore adjacency; the exterior of the square is dead. We determine C(1), …, C(25) = 0, 4, 6, 8, 11, 18, 28, 32, 43, 53, 63, 76, 88, 102, 119, 134, 151, 170, 188, 210, 230, 251, 276, 299, 325 and the further values C(29) = 435, C(31) = 497, C(32) = 528, C(33) = 562, C(37) = 704, C(39) = 782, C(41) = 863, C(45) = 1037, C(49) = 1228, C(53) = 1434, C(57) = 1657, and C(65) = 2150. The first unresolved case satisfies 350 ≤ C(26) ≤ 352, and every unresolved size n ≤ 50 has a gap of at most five cells.

A live 2 × 2 block is an isolated Moore component, so every connected still life with more than four cells is block-free. Combining this local obstruction with the Chu–Stuckey wastage identity yields finite-state boundary relaxations, and exact min-plus composition of edge automata and corner relations gives, for every n ≥ 14, C(n) ≤ min{M(n), ⌊(4n² + 5n − dn mod 8)/8⌋} with (d0, …, d7) = (26, 23, 18, 23, 20, 23, 26, 11), where M(n) is the unrestricted maximum. Explicit period-eight band families give C(n) ≥ n(n+1)/2 − 4 for every n ≥ 1, with equality of the constant at n = 5 and n = 8, and hence lim C(n)/n² = 1/2.
