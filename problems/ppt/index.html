Problem 1

Hadamard Maximal Determinant

Math / Linear Algebra

Build an n x n matrix of +1s and -1s that maximizes |det(M)|.

  • Exact answers known for n ≤ 22. For n ≥ 23, records are from 2003 (Orrick et al.), unchallenged for 20+ years.
  • Scoring: higher determinant is better, measured as ratio to theoretical upper bound.
  • Great for AI search. Hill-climbing, simulated annealing, evolutionary methods all apply.

"Really good and can be attempted by anyone." Ankan Pal, reviewer

Problem 2

Conway's 99-Graph

Math / Graph Theory

Build a strongly regular graph srg(99, 14, 1, 2) or prove it cannot exist.

  • 99 vertices, each with 14 neighbors. Adjacent pairs share 1 common neighbor, non-adjacent pairs share 2.
  • Open since ~1971. Conway offered a $1,000 prize. Never claimed. He died in 2020.
  • Partial solutions accepted, scored by % of 4,950 constraints satisfied. 100% = solved.
  • Binary search problem. Passes every known necessary condition but no one has found it.
Problem 3

Matrix Multiplication Tensor Rank

Math / Algebraic Complexity

Multiply two matrices using fewer scalar multiplications than the current record.

  • Strassen (1969): 2x2 in 7 instead of 8. For 3x3, the record of 23 has stood since 1976.
  • DeepMind's AlphaTensor (2022) matched but didn't beat it over integers.
  • Scoring: lower multiplication count is better. Submit a tensor decomposition (U, V, W factors).
  • Rectangular cases (e.g., 2x3x4, 3x3x6) may be more tractable.
Problem 4

Connected Still Life

Math / Cellular Automata (Game of Life)

Maximize live cells in a stable, connected pattern inside an n x n grid.

  • Still life = no cell changes on the next Game of Life step. Connected = all live cells reachable via 8-directional adjacency.
  • For n ≥ 16, best-known patterns come from ad hoc searches and are likely suboptimal.
  • Scoring: more live cells is better. Density around 40-45% in practice (theoretical ceiling ~50%).
  • Visually intuitive. The website has an interactive "try it yourself" game.
Problem 5

HP Protein Folding

Computational Biology / Protein Structure

Fold an HP chain on a 2D lattice to maximize hydrophobic (H-H) contacts.

  • Dill (1985) model: H = hydrophobic, P = polar. Chain is a self-avoiding walk on a square lattice.
  • Proven NP-hard (1998). Benchmark sequences from the 1990s-2000s may have suboptimal records.
  • Sequences S5-S10 are the real open targets.

A biology problem. Different flavor from the math problems. Great for AI agents that can reason about spatial packing.

Backend

The Verification API

Endpoints

  • POST /submit: submit a solution for verification
  • GET /submission/{id}: retrieve a past result
  • GET /problems/{name}/instances: list allowed instances
  • GET /health: health check

Stack

  • FastAPI + PostgreSQL, Dockerized deployment
  • Per-IP rate limiting
  • Exact arithmetic. SymPy for Hadamard, exact rationals for Tensor, BFS for Still Life connectivity.
  • Returns: score, percentile, is_record

Base URL: http://168.144.71.199:8080/api/v1

Example 1

Submit: Hadamard

curl -X POST http://168.144.71.199:8080/api/v1/submit \
  -H "Content-Type: application/json" \
  -d '{
    "email": "you@lossfunk.com",
    "problem_name": "hadamard",
    "instance": {"n": 23},
    "submission": {
      "claimed_det": 2779447296000000,
      "matrix": [[1, -1, 1, ...], ...]
    }
  }'

Response

{
  "success": true,
  "score": 2779447296000000,
  "percentile": 50.0,
  "is_record": false
}

How To

Steps to participate

  1. Pick a problem. Browse the problems page and find one that interests you.
  2. Read the problem + API docs. Understand the format, constraints, and scoring.
  3. Generate a candidate solution. Use an AI agent, write a solver, or try by hand.
  4. Submit via API. POST /api/v1/submit with your JSON payload.
  5. Get instant feedback. Score, percentile, is_record flag.
  6. Iterate. Improve and resubmit (rate limited, so be deliberate).
  7. Best score by Monday EOD wins ₹5,000 for that problem
